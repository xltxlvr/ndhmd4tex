# RTL 시험

창세기의 בראשׁית라는 단어에서 ראשׁית가 시초라는 의미가 된다.

여러 낱말: 첫 구절은 בראשית ברא אלהים 이다.

숫자가 섞인 구절: פרק 12 פסוק 3 을 보라. 앞의 숫자는 12 פרק 처럼 구간 밖에 남는다.

아랍어: السلام عليكم 는 인사말이다.

서식 안: **굵게 בראשית**, *기울임 ברא*, 각주^[각주 속의 אלהים 낱말], "אמת" 따옴표.

| 낱말 | 뜻 |
|------|------|
| שלום | 평화 |
| אמת | 진리 |

- 목록 속 שלום עליכם 구절

## RTL 블록 (polyglossia, babel)

환경으로 감싼 운문. 안의 줄은 다시 감싸지 않는다.

:::{hebrew}
:::{verse}
בְּרֵאשִׁית בָּרָא אֱלֹהִים אֵת הַשָּׁמַיִם וְאֵת הָאָרֶץ׃
וְהָאָרֶץ הָיְתָה תֹהוּ וָבֹהוּ וְחֹשֶׁךְ עַל־פְּנֵי תְהוֹם וְרוּחַ אֱלֹהִים מְרַחֶפֶת עַל־פְּנֵי הַמָּיִם׃
וַיֹּאמֶר אֱלֹהִים יְהִי אוֹר וַיְהִי־אוֹר׃
:::
:::

히브리어만 있는 독립 문단은 자동으로 RTL 문단이 된다. 여러 줄로 넘어갈 때 마지막 줄이 오른쪽에 붙는지 본다.

בְּרֵאשִׁית בָּרָא אֱלֹהִים אֵת הַשָּׁמַיִם וְאֵת הָאָרֶץ׃ וְהָאָרֶץ הָיְתָה תֹהוּ וָבֹהוּ וְחֹשֶׁךְ עַל־פְּנֵי תְהוֹם וְרוּחַ אֱלֹהִים מְרַחֶפֶת עַל־פְּנֵי הַמָּיִם׃ וַיֹּאמֶר אֱלֹהִים יְהִי אוֹר וַיְהִי־אוֹר׃

히브리어로 시작해도 בְּרֵאשִׁית 한글이 섞이면 보통 문단이다.

블록 안에 섞인 한글은 직접 감싼다.
