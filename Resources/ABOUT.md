# `Resources` 예제 파일의 설명 

## 표준 LaTeX 클래스 

`article.nmd` ::  `\documentclass{article}`로 하는 예제. samples의 `article_sample/`이 사용한다.
`report.nmd`, `book.nmd` ::  표준 LaTeX 클래스. kotex 없음.
`book.nmd` ::  표준 book 클래스. kotex 없음.
`articlekotex.nmd` ::  document class는 article이고 한국어 사용 예제. `article_kotex_sample.md`가 사용한다.
`reportkotex.nmd` ::  `report.cls` + `kotex.sty`
`bookkotex.nmd` :: `book.cls` + `kotex.sty`

## oblivoir 클래스 

`articlelike.nmd` ::  문서 클래스는 `oblivoir`이지만 `article` 모드로 작성하는 문서의 preamble 예제. samples의 `integral_measure_essay.md`가 사용한다.
`oblivoirbook.nmd` ::  문서 클래스 `oblivoir`에 `[chapter]` 옵션.

## beamer 

`beamermd.nmd` ::  beamer 설정

## mapping yaml 샘플

`postit.yaml` ::  샘플의 postittest.md가 사용함. postit 패키지 활용.
`lshort-ko_example.yaml` :: 샘풀의 lshort-ko_example.md가 사용. showexam 등.
`amsthm.yaml` ::  `theorem`, `corollary`, `lemma`, and `proof`.
